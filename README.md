✏️ หลังจากอยู่กับความเสถียรมาพักใหญ่ ก็เริ่มรู้สึกอยากลองของใหม่บ้าง ส่วนใครที่ไม่ได้อยากลองของใหม่ เน้นใช้งานแบบเสถียร สามารถย้อนไปดูแนะนำการตั้งค่าต่าง ๆ หลังการติดตั้ง distro เจ้าดังอย่าง Fedora ตามลิงค์นี้ <a href="https://www.github.com/thavibordee/fedora-post-installation-guide-th">Fedora Post Installation Guide (ภาษาไทย)</a> ได้เลยนะครับ มีอัปเดตแก้ไขปัญหาเพิ่มเติมสำหรับผู้ใช้บางท่านที่เจอข้อความ error ตอน boot รวมถึงการลง tweaks หรือของตกแต่งต่าง ๆ เพิ่มตอนท้ายให้ด้วยครับ
<p></p>
สำหรับคราวนี้ หลังจากได้มีโอกาสลองใช้งานอีกหนึ่ง distro ที่กำลังเป็นที่พูดถึง และได้รับความนิยมอย่างมาก นั่นก็คือ <b>Cachy OS</b> ก็ต้องยอมรับว่าส่วนตัวค่อนข้างหลงเสน่ห์ในความเร็ว การปรับจูนต่าง ๆ ที่ทำออกมาถือว่าทำได้ดีมาก ๆ โดย Cachy OS เหมือนถูกออกแบบมาเพื่อเน้นสำหรับสายเกมเมอร์โดยเฉพาะ แต่ถึงอย่างนั้นการใช้งานทั่วไปก็สามารถทำได้ดีเช่นเดียวกัน เรียกได้ว่าเป็นอีกหนึ่ง distro ที่น่าจับตามอง ตลอดจนสังคมผู้ใช้งาน (คอมมูนิตี้) ก็น่าประทับใจมาก ๆ เช่นกัน ในบอร์ดต่างประเทศมีการแลกเปลี่ยนความรู้ ใครที่เจอปัญหา ก็จะมีผู้ใช้มาช่วยกันตอบ ไม่เว้นแต่ผู้สร้างเองก็เข้ามาช่วยตอบด้วย ดูอบอุ่น และเป็นกันเองมาก ๆ
<p></p>
หลังจากลองใช้งาน Cachy OS มาได้พักใหญ่ ถึงแม้ว่าจะประทับใจกับการใช้งานหลาย ๆ อย่าง แต่ก็ต้องยอมรับว่าช่วงแรก ๆ ก็ต้องปรับตัวพอสมควร เพราะไม่ว่าจะเป็น Ubuntu และ Fedora ที่เคยใช้ ก็จะมีคำสั่งที่มีลักษณะเฉพาะของตัวเอง แต่ก็มีความคล้ายกันอยู่ ในขณะที่ Cachy OS นั้น จะเป็นอีกเรื่องนึงไปเลย จะไม่ใช่ <code>sudo apt</code> หรือ <code>sudo dnf</code> ที่เราคุ้นเคย แต่จะมีทั้ง <code>pacman</code> หรือ <code>paru</code> หรือ <code>yay</code> ซึ่งค่อนข้างเปิดโลกพอสมควร เหมือนต้องเริ่มนับหนึ่งใหม่กันเลยทีเดียว แต่พอใช้สักพักก็จะเริ่มชิน และด้วยความที่ส่วนตัวไม่ใช่สายเกมเมอร์ขนาดนั้น ก็เลยคิดที่จะลองใช้ต้นกำเนิดของ Cachy OS ดู ว่าจะประทับใจมากน้อยขนาดไหน ซึ่งนั่นก็คือ <b>Arch Linux</b> อีกหนึ่ง distro ในตำนานนั่นเอง
<p></p>
<hr></hr>
สำหรับ <b>Arch Linux</b> ส่วนตัวถือได้ว่าเป็น 1 ใน 3 เสาหลักของวงการ Linux ก็ว่าได้ ซึ่งวิธีการติดตั้งค่อนข้างมีความเป็นเอกลักษณ์เฉพาะตัว ไม่เหมือนกับ Ubuntu (Debian) หรือ Fedora ที่ค่อนข้างจะติดตั้งได้ง่ายกว่า ส่วนหนึ่งน่าจะเพราะตัวช่วยติดตั้งที่ทำออกมามีความ user-friendly มากกว่าของ Arch Linux ที่เหมือนเป็นลูกผสมระหว่างการพิมพ์คำสั่ง กับการเลือกเมนูที่ต้องการ ซึ่งถ้าลองหาข้อมูลในอินเทอร์เน็ตก็มีข้อมูลยังไม่มากเท่าไหร่ รวมถึงสังคมของ Arch Linux ผู้ใช้ส่วนใหญ่มักจะแนะนำ (ไล่) ให้ไปดู Archwiki แทน ผมก็เลยถือโอกาสทำสรุปเวอร์ชันภาษาไทยไว้ให้ หวังว่าน่าจะเป็นประโยชน์กับคนที่สนใจอยากลอง distro ตัวนี้นะครับ
<p></p>
เริ่มต้นก่อนอื่นต้องไปดาวน์โหลดไฟล์ <b>Arch Linux</b> มาก่อนนะครับ ดาวน์โหลดได้ที่ <a href="https://archlinux.org/download/">ลิงค์นี้</a> เลยนะครับ ดาวน์โหลดเสร็จแล้ว ก็สามารถเลือกใช้โปรแกรมที่ตัวเองชอบ ไม่ว่าจะเป็น Rufus หรือ balenaEtcher หรือ Ventoy ในการสร้าง Bootable Disk ได้เลยนะครับ เมื่ออุปกรณ์ทุกอย่างพร้อมแล้ว ก็ไปลุยกันได้เลยครับ

💡 ก่อนอื่นเราต้องเข้าไปที่หน้า bios ของเครื่องก่อนนะครับ (วิธีเข้า bios ของโน้ตบุ๊คแต่ละยี่ห้อก็จะแตกต่างกันออกไป ถ้าใครไม่ทราบลองพิมพ์ยี่ห้อโน้ตบุ๊คของตัวเอง + วิธีการเข้า bios ดูนะครับ) พอเข้ามาในหน้า bios แล้ว ให้ไปปิด secure boot และตั้งค่าให้ทำการ boot ผ่าน usb ที่เราเตรียมไว้นะครับ
<p></p>
หลังจากที่เรา boot bootable usb ที่เราเตรียมไว้แล้ว ขั้นตอนนี้ถ้าใครที่ใช้สาย lan เชื่อมต่ออินเทอร์เน็ตอยู่ สามารถข้ามขั้นตอนนี้ไปได้เลย แต่ถ้าใครที่ต้องเชื่อมต่อ wifi เราต้องเริ่มพิมพ์คำสั่งกันก่อนนะครับ โดยเริ่มด้วย...
<pre>iwctl</pre>
ตามด้วยคำสั่ง
<pre>device list</pre>
จากนั้นจะแสดงรายการของเครื่องเรา ให้เราพิมพ์คำสั่งนี้ต่อ (mode) (name) scan สมมติในที่นี้ คือ station และ wlan0
<pre>station wlan0 scan</pre>
ตามด้วยคำสั่ง
<pre>station wlan0 get-networks</pre>
หลังจากนั้นจะปรากฏลิสต์สัญญาณ wifi ในบริเวณนั้นขึ้นมา ให้เราพิมพ์คำสั่งต่อไปนี้ โดย SSID คือขื่อ wifi ที่เราต้องการเชื่อมต่อ
<pre>station wlan0 connect "SSID"</pre>
<p></p>
จากนั้นจะปรากฏข้อความให้เราใส่ password ของ wifi ที่เราทำการเชื่อมต่อ โดยตอนพิมพ์จะปรากฏเป็น <code>****</code> นะครับ เพียงเท่านี้ก็เชื่อมต่อ wifi ได้เรียบร้อย
<p></p>
เมื่อเชื่อมต่อ wifi ได้แล้ว ขั้นตอนต่อมาให้พิมพ์คำสั่ง <code>exit</code> จากนั้นเราสามารถตรวจสอบการเชื่อมต่อได้ โดยพิมพ์คำสั่ง
<pre>ping google.com</pre>
เมื่อค่า ping ส่งกลัมาเรียบร้อย ขั้นต่อมาก็ให้เราทำการอัปเดตสคริปต์ต่าง ๆ เป็นเวอร์ชันล่าสุดก่อนด้วยคำสั่ง
<pre>pacman -Sy</pre>
เมื่อทุกอย่างเรียบร้อยแล้ว ก็ถึงเวลาที่รอคอย พิมพ์คำสั่งต่อไปนี้ เพื่อเตรียมติดตั้ง <b>Arch Linux</b>
<pre>archinstall</pre>
